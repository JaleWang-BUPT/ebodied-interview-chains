# 追问链格式规范 v0.1

每条链是一个 `<details>` 折叠块（纯 HTML5 原生折叠，零 JS）。Markdown 源文件中格式如下：

````markdown
<details class="chain">
<summary><span class="lv lv-l2">L2</span> <span class="freq">🔥×4</span> <b>C03</b> · 推理 3Hz 但机械臂需要 50Hz 控制频率，怎么办？</summary>

**答**：……（≤350 字，直给结论与要点）

**追问 1**：为什么会出现抖动，怎么平滑？
**答**：……

**追问 2**：Temporal ensembling 和 RTC 怎么选？
**答**：……

**深挖**：部署假设被打破怎么办（桌面高度不固定、深度敏感任务）？（可选第 3-4 层）

**易错**：只答"插值"不说插值轨迹与离散拟合的本质差异。

**实录**：[牛客·云鲸 2026-02](URL) + [offerseed #6 2026-09](URL)
</details>
````

## 规则

1. **编号**：`C` 前缀 + 卷内两位序号（C01、C02…）；跨卷不连续
2. **难度标签**：L1 必会 / L2 进阶 / L3 顶级 lab，按追问链最深层定级
3. **频次**：🔥×N = 独立来源数（不同帖子/不同作者），跨平台各自计 1；`〔整理〕`类来源最多计 1
4. **主答 ≤350 字**；每个追问答 ≤150 字；深挖层可以短到一句话（"承认边界 + 给出排查方向"也是正确答案）
5. **易错**必须有——写面试官实测中候选人栽过的点，不写泛泛的"注意细节"
6. **实录行**必须给真实 URL；两个来源拼成的链要分别标注各自覆盖的层
7. **链内不出现未在调研中出现过的"模拟追问"**——若某层是推理补全而非实录/整理证据，在行内标注〔推断〕
8. 每卷开头放导语：本卷追问模式总结（来自 research 调研结论）+ 使用建议

## 网页渲染

- 每卷一个 Markdown → 单文件静态 HTML（`site/volN.html`），CSS 内联、响应式、`<details>` 原生折叠，无 JS 依赖
- 主索引 `site/index.html`：卷目录 + 各卷链数/节点数 + 更新日期
- 数学公式用 MathJax CDN，代码高亮用 highlight.js CDN（内容不依赖 CDN 可读）
