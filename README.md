# 具身智能面试追问链 · Embodied Interview Chains

> 按面试官真实下钻路径组织的具身智能（Embodied AI）中文面试题库。
> 每条不是孤立的一道题，而是一条**追问链**：主问 → 追问 → 深挖——还原"你说到哪个词，面试官就顺着哪个词往下问"的真实面试动态。

**状态**：🚧 调研完成，内容生产中（见下方进度）

---

## 为什么做这个

市面上已有的题库把面试题做成**平铺卡片**：一问一答，背完为止。但真实面试不是名词解释——面试官会从你的回答里抓一个词继续追：参数怎么定的？真机上会怎样？为什么不用现成的？普通题库练的是"知道"，追问链练的是"扛得住往下钻"。

本项目的所有追问链都有**一手面经出处**：来自牛客、知乎、CSDN、GitHub 上候选人逐字记录的真实面试过程（宇树、智元、云鲸、傅利叶、京东探索研究院、跨维、银河通用、小鹏等公司的具身智能/机器人算法岗），以及面试官本人撰写的提问逻辑自述。

## 与其他题库的差异

1. **追问链结构**：每条链 = 主问 + 2-4 层追问 + 易错点，按真实面试的下钻顺序排列，标注〔实录〕/〔整理〕来源分档
2. **真机排障独立成卷**：摔倒排查、板子死机、传感器时间同步、12V 只读到 5V……这些"工程岗分水岭题"在现有题库里是空白
3. **项目深挖防御指南**：面试官如何攻击你的简历项目（必要性拷问、数字核对、反事实假设题），以及怎么防——来自面试官本人自述
4. **考与不考的边界**：哪些公司考手撕、哪些不考；追问深度在实录中的真实分布

## 题源与质量规范

- 题目必须来自**公开一手面经**（牛客 / 知乎 / CSDN / GitHub 实录），每条标注来源 URL 与分档；不接受"我觉得会考"的编造题
- 同一下钻路径需在 ≥2 个独立来源复现才升为主链，否则降为附注
- 答案 ≤350 字 + "易错"一句；不写长篇推导
- **执行 AI ≠ 审查 AI**：所有答案经另一组独立模型交叉审查，多轮收敛后发布
- 已知 CSDN 存在内容农场式"面试题"批量帖（公司归属与追问系编造），已识别并剔除
